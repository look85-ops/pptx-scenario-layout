# pptx-scenario-layout

Актуализация управляющих презентаций PowerPoint по сценарию корпоративного курса.
Проверено на курсах на 200–500 слайдов. Три кита:

1. **Клонирование вместо создания.** Новый контент — не «с нуля», а копия
   слайда-образца с заменой текста. Фирменное оформление сохраняется,
   layout'ы не ломаются.
2. **Сценарий — источник истины.** Порядок и содержание берём из сценария,
   даже если в файле всё по-другому.
3. **Раскладка от конца к началу.** Перенос слайдов через PowerPoint COM
   (`MoveTo`) от последней позиции к первой — уже размещённые слайды
   не сбиваются.

Методика выросла из реального кейса: 202 слайда, 97 переносов, ~40 минут
вместо 2 дней ручной перетасовки. Валидация: порядок = карте, скрытые слайды
сохранены, контент не повреждён.

## Зачем

При актуализации учебных курсов, очных и не только.
Когда нужно добавить новый контент, обновить старый,
скрыть устаревший и переставить всё в порядок сценария. Руками это часы
работы, нервы и ошибки.

## Полный workflow

```
сценарий (docx)  ─▶  операции (clone/edit/hide)  ─▶  карта (порядок)  ─▶  валидация
```

1. **Анализ сценария.** Новый контент в сценарии помечен (например, цветом).
   Из него собираем список операций: что добавить, что изменить, что скрыть.
   Что на слайд НЕ выносим — ремарки для ведущего (`Примечание:`,
   `Преподаватель:`).
2. **Операции** (`update.ps1`): клонировать образец + заменить текст +
   метка «Новый»/«Изменено»; отредактировать существующий слайд; скрыть
   устаревший. Как выбирать образец-шаблон под структуру контента — см.
   [TEMPLATES.md](TEMPLATES.md).
3. **Карта порядка** (`layout.ps1`): финальный порядок слайдов = карте
   сценария. Раскладка от конца к началу.
4. **Валидация** (`validate.ps1`): порядок = карте, скрытые сохранены,
   контент на месте.

## Требования

- Windows + установленный PowerPoint (COM).
- PowerShell 5.1+.

## Использование

### Шаг 1. Операции: добавить / изменить / скрыть

Составьте `operations.json` (пример: [operations.example.json](operations.example.json)):

```json
{
  "operations": [
    { "op": "edit",  "find": "Beta task",        "replace": { "Beta task": "Beta task v2" }, "tag": "Изменено" },
    { "op": "clone", "from": 2, "to": 4,          "replace": { "Beta theory": "New theory" }, "tag": "Новый" },
    { "op": "hide",  "find": "Omega outro" }
  ]
}
```

- `edit` — найти слайд по тексту (`find`) или номеру (`slide`), заменить
  подстроки в фигурах, добавить метку.
- `clone` — дублировать слайд-образец `from`, заменить текст, добавить метку,
  переместить на позицию `to`.
- `hide` — скрыть слайд (`show="0"`), он остаётся в файле, но не показывается.

Запуск (создаст резервную копию `_backup.pptx`):

```powershell
powershell -ExecutionPolicy Bypass -File update.ps1 -PptxPath ".\deck.pptx" -Operations "operations.json" -Backup
```

### Шаг 2. Карта и раскладка

`target_order.txt`: строка N = исходный номер слайда, который должен оказаться
на позиции N (1-based, пустые строки и `#` игнорируются). Полная перестановка:
0 пропусков, 0 дублей — иначе скрипт не запустится.

```powershell
powershell -ExecutionPolicy Bypass -File layout.ps1 -PptxPath ".\deck.pptx" -MapFile "target_order.txt" -Backup
```

### Шаг 3. Валидация

```powershell
powershell -ExecutionPolicy Bypass -File validate.ps1 -PptxPath ".\deck.pptx" -MapFile "target_order.txt" -OriginalPath ".\deck_original.pptx"
```

`validate.ps1` проверит:
- количество слайдов совпадает с картой;
- порядок `sldIdLst` последователен;
- число скрытых слайдов (`show="0"`);
- если задан `-OriginalPath` — контент каждого слайда соответствует исходному
  (по нормализованному тексту; чистые числа — авто-номера — игнорируются).

## Известные грабли (проверено на практике)

- **Кодировка скриптов.** PowerShell 5.1 ломает `.ps1` с кириллицей без BOM.
  Если добавляете русские комментарии — сохраняйте файл в UTF-8 с BOM.
- **Имена файлов.** В путях может быть длинное тире «—», а не дефис.
  Ищите файлы по glob/`Where-Object`, а не хардкодьте строки.
- **Консоль.** Кириллица в выводе терминала показывается кракозябрами
  (cp866/cp1251). Пишите результаты в UTF-8-файлы и читайте их.
- **Перенумерация.** После COM-Save PowerPoint переименовывает slide-файлы:
  `slide{i}.xml` = новый i-й слайд. Это нормально — валидируйте по тексту,
  а не по старым номерам файлов.
- **Поиск слайда по тексту.** Используйте короткие уникальные подстроки,
  не пересекающие перенос строки (`\x0b` в тексте PowerPoint ломает поиск).
- **Неиспользуемые слайды** — скрывайте (`show="0"`), а не переносите в конец,
  иначе человеку сложно ориентироваться в файле.
- **«Грязный» образец.** После клонирования могут остаться текстбоксы
  с оригинальным текстом — замените/почистите их.

## Структура

```
update.ps1             # операции: clone / edit / hide (новый контент)
operations.example.json# пример таблицы операций
layout.ps1             # раскладка по карте (MoveTo, от конца к началу)
validate.ps1           # проверка после правок
target_order.txt       # пример карты порядка
TEMPLATES.md           # как подобрать шаблон под структуру контента
```
